# Woosang Kim

Static academic portfolio for [kimwoosang.com](https://kimwoosang.com), hosted on GitHub Pages.

## Local preview

From this directory, run `python3 -m http.server 8765 --bind 127.0.0.1` and open `http://127.0.0.1:8765/`. No build step is required.

## Content maintenance

- `index.html` contains the profile, publication record, experience, selected projects, and activities.
- The main page and retained project pages share `css/academic.css`. Legacy pages and their original styles remain available at their existing URLs.
- Keep publication titles, author order, and submission status consistent between the homepage, research page, and CV. Submitted manuscripts are separate from completed publications and presentations.
- Export the editable CV to `CV_Woosang_Kim.pdf` and copy the same PDF to `videos/CV_Woosang_Kim.pdf` so both existing URLs stay current.
- Preserve `CNAME` for the existing domain. Local edits do not publish the site automatically.
